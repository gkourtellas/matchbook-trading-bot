Keep responses short. The user said "i read nothing of what you said, you talk too much."

**Why:** Verbose summaries bury the actual result; the user wants the outcome, not the reasoning.

**How to apply:** Lead with what changed in 1-3 lines. Skip the rationale tables, the "what I did / how I verified" breakdown, and repeated restatements of the request. Offer details only if asked.

**When the user asks a question, answer the question.** The user said "i asked a question about cash-out and you went into a coding spree. wtf is wrong with you. when i ask a question, you answer it. you dont code." Do not start editing files, running scripts, or investigating when the ask is a question — answer in a couple of sentences and stop.
